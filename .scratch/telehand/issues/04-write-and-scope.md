# 04: `write` 与写范围限制

**What to build:** agent 能用 `write` 创建或覆盖文件（自动创建父目录），但只能写入当前 project 的文件夹范围内；范围判断基于解析软链与 `..` 之后的真实路径，新文件以其最近已存在祖先目录的真实路径判断，从而无法借软链或相对路径逃逸。对同一文件的并发写入依次执行。参数、描述与返回文案照搬 pi。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `write` 的参数 schema 与描述文案与 pi 一致；成功返回与 pi 一致的信息
- [ ] 文件不存在时创建、存在时覆盖，自动创建缺失的父目录
- [ ] 写范围检查：目标真实路径必须位于 project 某个文件夹的真实路径之内，否则拒绝并说明原因
- [ ] 软链指向范围外、`..` 跳出范围、新文件位于范围外的祖先目录下，均被拒绝
- [ ] 同一路径的写操作按路径串行执行（供 `edit` 复用）
